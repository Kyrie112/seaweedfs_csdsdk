# M3 可互斥(可选):卷数据文件代次与读租约

> 目标:让区间失效在**下发前**被发现,而不是读完之后才失败;
> 为高频整理或强一致场景提供保障。
> 方案依据:[PLAN 第 5.4 节](../DISTRIBUTED_CONSISTENCY_PLAN.md)。
>
> **本里程碑是可选档**:是否实施由 M1 的性能数据与 M2 的故障注入结论决定(见决策门 D1/D2)。

## 1. 范围与验收

**做什么**

- 为卷数据文件引入单调递增的"代次";
- 代次随描述符下发并在下发前校验;
- 可选:读租约(计算期间推迟整理)。

**不做什么**:不做全局共识、不改复制协议。

**出口条件**

| 判据 | 标准 |
| --- | --- |
| 提前发现 | 代次不匹配时在**下发前**返回 `stale_range` |
| 单调性 | 并发整理压力下代次严格单调,无回退 |
| 吞吐 | 整理吞吐回归在预算内(需在 T3.4 约定阈值) |

## 2. 步骤

### T3.1 卷数据文件代次

- **目标**:给"数据文件被替换"这件事一个可传递的编号;
- **前置**:M1 数据表明需要(决策门 D1);
- **改动**:`weed/storage/volume.go`、`weed/storage/volume_vacuum.go`;
- **关键流程**:
  1. 在卷对象上增加 `dataGeneration uint64`(原子访问);
  2. **只在数据文件替换的临界区内**自增——该临界区已经持有
     `dataFileAccessLock` 写锁(`volume_vacuum.go:174`、`:354` 附近),
     因此无需引入新锁;
  3. 提供并发安全的读取接口供描述符构造使用;
  4. 日志中输出代次变化,便于与实验数据对齐;
- **验证与通过标准**:单测模拟多次整理,断言代次严格递增且无并发回退(可用 race detector);
- **产出**:代次字段与访问接口;
- **回滚**:revert;新字段不影响既有行为;
- **风险**:代次必须在**同一临界区**内与文件替换一起完成,否则会出现"文件已换、代次未变"的窗口。

### T3.2 代次随描述符下发与校验

- **目标**:在下发前发现区间已失效;
- **前置**:T3.1;
- **改动**:`weed/storage/volume_read.go`(描述符字段)、`weed/server/csd_compute.go`(校验与下发);
- **关键流程**:
  1. `NeedleComputeRegion` 附上当前代次;
  2. Filer 在令牌中携带期望代次(`vgen`);
  3. Volume 下发前比对:不一致 → `stale_range`(复用 M2 的重试策略);
- **验证与通过标准**:注入"整理与计算并发",断言请求在整理后能重试成功或显式失败;
- **产出**:字段与校验;
- **回滚**:revert;
- **风险**:与 M1 的头部自校验功能重叠,需明确二者关系(代次更早失败,头部自校验更精确)。

### T3.3 读租约(可选)

- **目标**:彻底避免"计算期间整理",换取最强的读稳定性;
- **前置**:T3.2;
- **改动**:`weed/storage/volume.go`;
- **关键流程**:
  1. 计算请求在卷上登记一个短期租约(带超时);
  2. 整理在租约存续期间**推迟**(而非失败),并按可观测指标记录推迟时长;
  3. 租约超时自动释放,避免整理被永久饿死;
- **验证与通过标准**:压力测试下计算全部成功,整理仅被推迟且最终完成;
- **产出**:租约实现;
- **回滚**:revert;建议以开关控制,默认关闭;
- **风险**:整理被长期推迟会导致空间无法回收。**这是本方案中风险最高的一项**,
  必须设定推迟上限与告警。

### T3.4 并发压力回归

- **目标**:量化代次/租约对整理的影响;
- **前置**:T3.1–T3.3;
- **改动**:存储层测试 + 实验脚本;
- **关键流程**:在持续整理的同时跑计算负载,记录:计算成功率、整理完成时间、空间回收速率;
- **验证与通过标准**:三项指标均落在预先约定的预算内;
- **产出**:压力测试数据;
- **回滚**:—
- **风险**:若整理吞吐明显下降,应回退 T3.3(保留 T3.1/T3.2)。

## 3. 决策门 D3

M3 结束时二选一:

- 保留完整方案(代次 + 租约);
- 或**回退读租约**,仅保留代次校验(推荐默认),理由是租约对空间回收的影响需要更长时间观察。
