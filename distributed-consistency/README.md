## 使用约定

1. **先登记再动手**:每个步骤开始前在 `进度看板.md` 把状态改为 🟡,并写下开始日期;
2. **一步一记录**:完成后按 `templates/模板-步骤开发记录.md` 补一份记录,附上可复现的命令与原始输出;
3. **证据优先于结论**:任何"验证通过"都必须能指向具体命令、数据文件或测试输出;
4. **不达标就回退**:若某步骤的完成判据不满足,状态退回 ⬜ 并记录原因,不允许"带病推进";
5. **决策留痕**:任何偏离 PLAN 的决定,必须在当天的 `journal/` 中记录理由;
6. **保持文档与代码同步**:提交代码的同一个提交里更新本目录对应记录。

**方案变更**:2026-10-12 决定采用"版本保留 + 引用计数 + 延迟回收"(MVCC 式)作为
一致性的主路径——老任务读老版本、新写入追加为新版本、引用归零后 GC。
M1 的检测能力由主路径退化为兜底。详见
[PLAN 5.4 节](../分布式一致性问题分析与开发计划.md)与
[journal/2026-10-12-M3版本化设计决策.md](journal/2026-10-12-M3版本化设计决策.md)。
