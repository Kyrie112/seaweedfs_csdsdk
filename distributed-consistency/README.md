## 状态图例

| 标记 | 含义 |

| ⬜ 未开始 | 尚未启动 |

| ⛔ 阻塞 | 存在需要外部输入或决策的阻塞项 |
| ➖ 不适用 | 经评估后决定不做(需在 PROGRESS 中写明理由) |

## 使用约定

1. **先登记再动手**:每个步骤开始前在 `PROGRESS.md` 把状态改为 🟡,并写下开始日期;
2. **一步一记录**:完成后按 `templates/step-record.md` 补一份记录,附上可复现的命令与原始输出;
3. **证据优先于结论**:任何"验证通过"都必须能指向具体命令、数据文件或测试输出;
4. **不达标就回退**:若某步骤的完成判据不满足,状态退回 ⬜ 并记录原因,不允许"带病推进";
5. **决策留痕**:任何偏离 PLAN 的决定,必须在当天的 `journal/` 中记录理由;
6. **保持文档与代码同步**:提交代码的同一个提交里更新本目录对应记录。
